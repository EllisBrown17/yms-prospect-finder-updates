# NORTHBROWN 1.5.0

Quality-of-life release for the NORTHBROWN Lead Engine.

## Scan Intelligence
- Live phase-by-phase scan explanation and findings
- Progress, elapsed time and learned ETA
- Pause, resume and safe stop
- Crash/restart recovery
- Smart skip and stale-data detection
- Fast, Smart and Full scan modes
- Automatic deep analysis for strong prospects
- Live score/email/failure/AI/Places counters
- Approximate OpenAI spend indicator (Google billing is not guessed)
- Expandable activity log, scan history and retry-failed flow
- Background scanning, completion notifications and post-scan summary

## Prospect workflow
- Undo for accidental stage/suppression/rejection changes
- Mac keyboard shortcuts
- One-click Quick Demo page generation from verified prospect evidence
- Preview, HTML download, share link and compliant email sharing
- Demo copy is constrained not to invent reviews, awards, accreditations, services or other unsupported claims

The public demo share/email buttons require a real HTTPS Public Demo URL in Settings. Local 127.0.0.1 links are intentionally not shareable.
